Record first, then export the points

To record an iPhone route as GPX with Whereday, start tracking before your trip, stop when you finish, then choose Points and GPX in Export. Select the right date range, preview the result, and save the file to Files or share it with a compatible route viewer.

From version 1.8, new users need an eligible trial, subscription, or Lifetime purchase to track. Existing users keep free tracking and prior purchase rights. Supported import and Export Preview are free. New users from 1.8 retain exports after tracking access expires; existing free users keep their previous export-unlock requirement. This workflow exports a route recorded in Whereday; it does not extract old Apple Maps or Google Timeline history.

1. Record a short route

  1. Open Whereday and complete permission setup. Choose Always location access if you want recording to continue in the background.
  2. On the Map tab, start recording before you leave. Start enables GPS recording, visit monitoring, and significant location changes together.
  3. After a short walk or trip, stop recording. Stop ends both GPS and visit monitoring.
  4. Open Timeline and check the outing’s date, start and end times, and map. Confirm that it contains the part of the trip you intend to export.

Try this with a short session before relying on it for a full day. GPS can be noisy or unavailable, and permission changes or a stopped session can leave gaps. There is no separate passive visit-only switch. The recording reference explains distance filtering and auto-stop.

For a longer trip, choose an auto-stop duration that will not end early. Stop when you finish. Detailed GPS uses battery, and a larger distance filter trades route detail for fewer captured points; check the result before settling on a setting. Use the battery comparison checklist to compare your own recordings.

Export a route recorded on Apple Watch

If you recorded in the Whereday Watch app, transfer the route to its companion iPhone before exporting. This workflow uses Whereday’s saved points; it does not extract an Apple Workout or Apple Health route.

  1. Stop the recording on the Watch. Bring the paired devices together and open Whereday on both. If available, choose Sync Now on the Watch.
  2. Open the recording’s date in the phone’s Timeline. Inspect the outing, its map, and its start and end times. A Sync queued message is not confirmation that every point has arrived.
  3. On the phone, choose Points and GPX in Export, then select the recording’s dates. Review filters and Preview before saving. Points can include other recordings in that period; use the specific outing’s Export action when you need that outing alone.
  4. Open the saved file in the local GPX viewer. Compare its first and last point times, count, and shape with the phone copy. Keep pending Watch data while investigating missing points.

The Watch sync reference explains pending points and acknowledgements. Sync retries with the same record IDs are separate from importing a GPX file. Whereday does not import GPX.

2. Choose Points and GPX

  1. Open Export and choose Points as the data type. These are the recorded GPS locations that make up a path.
  2. Select GPX. If other formats are also selected, the export can produce additional files.
  3. Choose the date range for your recording. Review any time-of-day, accuracy, and GPS-glitch filters that could exclude points.
  4. Open Preview. Check the intended date and file contents before paying for or writing an export.
  5. Export. With a default folder configured, look there for the saved file; otherwise use the share sheet to save it in Files.

You can also open a specific outing in Timeline and use its Export action with GPX selected. For a full reference on filenames, date filters, and saving destinations, see export and restore compatibility.

3. Check the file in Files and your viewer

Find the exported .gpx file in the folder you chose. Confirm the filename and date before sending it elsewhere. If your destination application accepts GPX tracks, use its import or open-file action to select the file.

  • Check that the track covers the expected start and end locations.
  • Check timestamps against the trip. GPX times may be shown in UTC or converted to the viewer’s local timezone.
  • Look for gaps and separate segments instead of assuming every straight line represents captured movement.
  • Keep the original file if another tool rewrites or converts it.

GPX describes geographic data; it does not include a street map or guarantee that every app offers the same display. Files preview may show text or a file icon rather than drawing a route. A viewer that supports waypoints alone may not display a track.

Whereday exports recorded points. Do not assume the file follows the same road-matched line shown in a map preview. When consecutive points are more than ten minutes apart, the current exporter starts a new GPX track segment.

Open a track in gpx.studio

On a computer, open gpx.studio, choose File → Open…, and select the saved GPX. Use View → File tree to inspect its tracks and segments alongside the map. These controls are described in the viewer’s file help and view help.

Try the synthetic example below before opening your own location file. A map line connects the saved points; it does not prove continuous GPS coverage between them. Check segment boundaries and timestamps as well as the shape.

If the export is empty or the line looks wrong

For an incomplete Whereday day, use the missing visits and route points checklist to distinguish recording, display, Watch sync, and export issues.

  • No points in Preview: check the selected dates and filters, then open the same day in Timeline. Export cannot create a path that was not recorded.
  • Pins instead of a line: check whether you exported Visits rather than Points.
  • The path has gaps: check recording state, permission, and auto-stop. Inspect the original points before changing filters to include less accurate fixes.
  • File saved somewhere unexpected: check the default export folder before repeating the export. Some exports produce more than one file.
  • A viewer rejects the file: confirm it supports GPX 1.1 tracks and that the file was completely saved. Keep the original while checking the error.

Keep a separate copy for restoring your journal

GPX is a portable map format, but Whereday does not import GPX. To retain records you can import later, export visits and route points separately as supported Whereday JSON files and keep both. A map file is not a complete backup of every journal setting or outing edit. Follow the backup and restore checklist for a transferable copy of supported records.

For spreadsheet rows, CSV may suit your next task better. Read the format and restore matrix before choosing an archive format. For automatic copies, see scheduled exports; background execution is best effort.

Exported coordinates and times can reveal your movements. A file saved in cloud storage or sent to another app follows that destination’s privacy rules. Check the file before sharing it.
