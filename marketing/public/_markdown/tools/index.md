# Make sense of your location files

Practical tools for checking your own files before importing or converting them.

By [Cody Bontecou](https://isolated.tech), Whereday’s developer · Reviewed October 30, 2026

## [GPX viewer and file inspector](https://whereday.com/tools/gpx-viewer/)

Plot tracks and routes, check timestamps and invalid coordinates, and save CSV or GeoJSON with documented field limits. Your chosen file stays in your browser.

[Follow the worked inspection tutorial](https://whereday.com/blog/check-gpx-file/) with an invented five-point example.

Have a different file type? [Compare GPX, KML, GeoJSON and CSV](https://whereday.com/blog/gpx-kml-geojson-location-history/) before choosing a destination. The current viewer accepts GPX; renaming a file does not convert it.

## [Google Timeline JSON inspector](https://whereday.com/tools/google-timeline-inspector/)

Identify supported raw, semantic and device Timeline structures. Check coordinates and times, inspect findings and try invented examples before opening your own archive.

[Learn which Timeline JSON file you have](https://whereday.com/blog/google-timeline-json-formats/) and why browser counts can differ from a native import preview. Your selected file stays in the tool page.
